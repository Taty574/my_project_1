File Transfer Protocol (FTP)

Category: Protocols & Services

Definition

FTP (File Transfer Protocol) is a standard network protocol used for the transfer of computer files between a client and server on a computer network. It operates on the application layer of the TCP/IP protocol suite.

How FTP Works

FTP uses two separate channels for communication: a command channel for controlling the conversation and a data channel for transferring the actual files. The client initiates a connection to the server, and after authentication, it can upload or download files.

FTP in Web Development

FTP was traditionally the primary way developers "uploaded" their HTML and CSS files to a web server so the rest of the world could see them via the World Wide Web.

Note: Just like HTTP has a secure version (HTTPS), FTP has a secure version called SFTP (Secure File Transfer Protocol) which encrypts the data during the move.
