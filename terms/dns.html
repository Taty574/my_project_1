Domain Name System (DNS)

Category: Infrastructure & Navigation

Definition

The Domain Name System (DNS) is a hierarchical and decentralized naming system for computers, services, or other resources connected to the Internet. It associates various information with domain names assigned to each of the participating entities.

The Role of DNS

Computers communicate using IP Addresses, which are long strings of numbers. However, humans find it difficult to remember these numbers. DNS solves this by allowing us to use meaningful names.

  • The Lookup: When you type a URL into a browser, the DNS "resolves" that name into its corresponding IP address so the browser can load the correct resource.
  • Global Distribution: DNS is not stored on one single computer; it is distributed across millions of "Name Servers" globally.

History and Importance

Before DNS was invented in 1983, every computer on the network had to maintain a single file called HOSTS.TXT that listed every other computer's name and address. As the Internet grew, this became impossible to manage. DNS was created to automate this process and allow the Internet to scale to billions of users.
